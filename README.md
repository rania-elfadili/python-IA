# python-IA
📚 Repository Contents

1. Image Processing

Practical exercises focused on digital image processing using Python.

Topics covered:

Image loading and visualization using OpenCV and Matplotlib.

BGR and RGB color spaces.

Grayscale image conversion.

Image negative and color channel separation.

Image subsampling and quantization.

Contrast and brightness adjustment.

Image normalization and histogram analysis.

Histogram equalization.

Libraries: Python, OpenCV, NumPy, Matplotlib.

2. Natural Language Processing (NLP)

Practical exercises exploring text preprocessing and natural language processing techniques.

Topics covered:

Text and sentence tokenization.

Text cleaning and normalization.

Stopwords removal.

Lemmatization.

Text preprocessing using NLTK and spaCy.

Basic text representation techniques.

Libraries: Python, NLTK, spaCy, PyTorch.

3. Sentiment Analysis & Machine Learning

Practical work focused on text classification and sentiment analysis.

Topics covered:

Loading and exploring text datasets.

Text preprocessing.

Train/test data splitting.

Bag of Words and TF-IDF vectorization.

Classification using machine learning algorithms.

Model evaluation using Accuracy, Precision, Recall and F1-score.

Comparing different vectorization and classification methods.

Libraries: Python, Pandas, Scikit-learn, NLTK, Matplotlib, Seaborn.
